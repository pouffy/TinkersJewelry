# Tinkers' Jewelry Re-Socketed
**Modifiable Curio trinkets for Tinker's Construct 1.20.1+**

[Join My Discord](https://discord.gg/9N8cZh3hdB)

## Base Features:
### Ring
A simple trinket that fits into the "ring" slot. It consists of 2 parts:
- Cut Gem: Holds the special effect
- Plain Ring: Durability of the Ring and Amplification of the gem effect

## Gems
Gems are the most important part of any Jewelry. They determine what effect the trinket would have.
